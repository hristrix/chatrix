# Chatrix

Read Twitch, YouTube, Kick, and TikTok chat inside Minecraft, with message cards around your player, in front of the camera, or in a HUD corner.

Chatrix includes emotes, role badges, pinning, history and replay, blocked words and usernames, regex filters, role filters, sounds, and a visual appearance editor.

## Install

Requires Fabric Loader and Fabric API. Choose the matching jar for Minecraft 1.21.10, 1.21.11, 26.1, 26.2, or 26.3. The 26.1 jar also targets 26.1.1 and 26.1.2. Install Chatrix on the client.

Press `]` for settings, configure channels, then press `[` to connect. Run `/chatrix test Hello!` to try a message without a live stream. `/chatrix help` lists commands.
